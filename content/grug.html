Grug On Philosophy

A laymans guide to live good life like self-aware small brained

grug found https://grugbrain.dev/ and thinks very funny, grug dev clearly very old and wise, as young grug ignore many times and make same mistakes

so grug decide write too, even if not wise. but grug dislike computer, not outside, so no write about computer

grug very confused about outside, but very beautiful, so decide to sit in armchair and write about it instead

(on computer, inside)

grug not been outside much, but more than big brain, so hopes less confused

grug knows will change mind soon, always wrong. but also forget grug many times, become big brain, so grug write maybe remember

grug see big brain draw many big castles about outside on whiteboard but grug knows:

complexity demon! (all know: complexity very, very bad)

so grug afraid big brain keep drawing many details forever or castle will break when build

grug wants draw simple cave, but big brain not like

will get hate, but free country

grug likes real things

grug only fallen through chair once, so grug thinks chair solid

chair broken was pain, grug dislike. grug does not like what he dislikes and thinks all very silly who want grug write such things

grug see others make face that grug made when pain, so grug thinks others dislike too

grug thinks others like him, so grug nice to grug, and dislikes with them

grug confused that need many complex words to know that not hurt other

grug not alone

grug very sad when team of grugs that sang song he likes make less ball go into net than other team

if all no language, grug still very sad, so grug not think language is game! language pointer at thing, but grug only have 10 finger

if grug close eyes and use words to point at game, grug sees game

(not all of it, as grug has small brain, only remember important stuff)

grug thinks others also see game and not worried about difference, because not important stuff

So grug happy can talk with others

grug likes very big numbers

They cool

grug see many small ones and want number go up! number of grugs very low, number of grugs not sick low, grug on red planet in sky low, very sad

but grug knows some number bad, as big make feel sick, like grugs poking grugs with sticks, make pain! or big brain controlling grug, so grug become big brain and do nothing

But grug just put "-" in front of number, so still want go up

grug confused sometime about number, because change other numbers, but grug no worry, more important number still low

grug thinks grugs in pain saddest number, or grugs going poof

grug very confused if grug with four legs still grug

but grug poke with stick and look very sad, so grug thinks all is grug

except rock, when poke just fun

grug scared of not being grug

grug heard big brain say "no can think when grug not there, so grug no worry"

big brain silly (and try sell nice story for when not there, so afraid too)

grug knows not exist bad, because exist feel great! even when grug very sad, for very long time, grug not think of ending

too silly

(this also reason grug wants make tiny grugs, they not want not exist, so make them)

grug confused about big brain numbers

grug likes big numbers, but big brain likes other ones

grug likes numbers which count grugs or chairs, but big brain invent number first

this very funny

sometimes grug likes too, like how many balls go into net, but not real, so grug only find cute or sad

but not same sad as grug hurt other grug! big brain confused and takes all very seriously, so big brain sad all the time

sometimes grug wants club big brain on head lightly, so not sad anymore

but grug understands, big brain was taught by other big brain with biggest number, so not big brains fault. grug also happy, for big brain sometimes make clean water to make silly number go up, but not often

often make water dirty instead

grug still not worried, because number of big brains also silly number

grug certain

one weird number big brain like is "certainty"

grug confused, as grug sees things or not

more confusing when point at thing not yet happen

bad thing happen - but big brain said so - big brain happy!

grub wants much club big brain but not hurt even big brain

also big brain foretell many easy little things, now other big brain think know distant future

but future not written, but build, so might explode

grug not worried AI kill us all

big brain many fears, but biggest is other big brain

steal numbers

so big brain greatest fear is build mega big brain, steal all numbers

grug not worried, just scarred of big brain monster turn all grug into big brain

or maybe big brain monster really successful and make silly number go all the way up, so water very dirty and all grug die

very bad

big brain very risky

but big brain also thinks just make brain bigger enough, even though grug smaller brain and less confused, so maybe big brain fail

grug want build things

grug very lazy, so no build, but write this

but grug knows build one day, so grug life easy

grug also not want build things that do nothing, so grug wait. but not too long, otherwise turn big brain

grug wants build rocket, but too many grug in pain, so build no pain machine first

grug very happy with many other grugs helping, so pick any, grug chose not make old machine

thinks old grug in most pain, as brain goes compost and happy part gone, so old grug very confused and no fun, then go poof

also grug wants be young when on rocket

but not care what other grug build, as long as no pain machine

grug see other grugs forget chair

many better than big brain, all very happy, always singing! some even build, but weird shapes

very confused, because look like grug, but do nothing

grug thinks forget chair is real! eat too many mushrooms, forget stick make inside of grug come out

some also only sit, think reach biggest number of "Jhana"

think important number, because infect other grugs and make happy, but infection makes grugs sit, not build

this happy for big brain, but bad for grug, wants build things

grug happy

all in all, grug not need sit in armchair long

will go sleep now (grug likes sleep, many things solved there, no need use brain)

grug go outside tomorrow, or not

grug not know, but grug happy anyway. grug also can't change, but not matters

only matters machine build, so all grug happy

will happen, grug help maybe
