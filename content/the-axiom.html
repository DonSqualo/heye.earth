The Axiom

Everything I believe has one underlying axiom:

❗
The set of all possible statements that cannot be criticized contains only one element: this statement.

This implies any dogmatic claim cannot have truth value. Objectivity is unknowable.

There is no particular reason for holding this axiom, but it’s the simplest epistemological and moral axiom that is consistent with avoiding justified belief, which is a necessary condition for reaching the maximum in whatever one cares about.
